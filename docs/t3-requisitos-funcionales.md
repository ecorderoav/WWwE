# T3 · Requisitos funcionales

Autor: Erik Cordero Avilés

| ID | Descripción | Prioridad |
|---|---|---|
| RF-01 | El sistema permitirá al jugador crear una cuenta. | Alta |
| RF-02 | El jugador podrá iniciar sesión con su cuenta. | Alta |
| RF-03 | El jugador podrá cambiar el nombre de usuario. | Alta |
| RF-04 | El jugador podrá cambiar su contraseña. | Alta |
| RF-05 | El jugador podrá eliminar su cuenta. | Alta |
| RF-06 | El sistema mostrará un menú principal con las opciones de jugar, clasificaciones, perfil y configuración. | Alta |
| RF-07 | El sistema contará con dos niveles, uno en cada luna. | Alta |
| RF-08 | El jugador podrá saltar sobre los enemigos para eliminarlos. | Alta |
| RF-09 | Al empezar cada luna, la historia se mostrará con texto blanco sobre fondo negro; después, mientras el jugador juega, aparecerán textos en la parte inferior de la pantalla que la irán explicando. | Alta |
| RF-10 | Los niveles contarán con un cronómetro durante la partida. | Alta |
| RF-11 | El sistema guardará el progreso al completar un nivel. | Alta |
| RF-12 | El sistema permitirá al jugador continuar con su partida. | Alta |
| RF-13 | El sistema desbloqueará la segunda luna cuando el jugador complete la primera. | Alta |
| RF-14 | El juego permitirá al jugador reiniciar el progreso. | Alta |
| RF-15 | El sistema permitirá configurar el sonido y los controles. | Alta |
| RF-16 | La configuración de sonido y controles se guardará en la cuenta del jugador. | Alta |
| RF-17 | Al acabar una luna, el sistema guardará el mejor tiempo, solo en caso de que mejore la marca anterior. | Alta |
| RF-18 | El sistema permitirá consultar la clasificación de cada luna. | Alta |
| RF-19 | El juego contará con un segundo nivel en cada luna. | Media |
| RF-20 | Habrá un jefe final en cada luna. | Baja |
| RF-21 | Si un enemigo toca al jugador tres veces, este perderá la vida y tendrá que empezar el nivel de nuevo; si cae al vacío, morirá al instante. | Alta |
